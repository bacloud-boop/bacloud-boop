## ⚔️ MAIN QUEST · 当前任务

### [DNDFightSimulate](https://github.com/bacloud-boop/DNDFightSimulate)

**龙与地下城跑团战斗测试器 · Unity / C#**

把战斗搬进测试场，给冒险多一点准备，给团灭少一点意外。

配置角色属性、职业与武器，在网格地图上部署角色，与可配置的训练木桩进行战斗。用投骰表现和战斗日志，查看每一次命中与伤害的结算。

| 工作台 | 可以做什么 |
| :--- | :--- |
| 🧙 角色配置 | 调整属性、职业等级与武器，测试不同配置 |
| 🗺️ 战术试验 | 网格部署、回合移动与借机攻击 |
| 🎲 投骰与记录 | 立体或简洁投骰表现，查看战斗日志 |
| 🔁 再试一次 | 重置战斗，调整配置，继续验证想法 |

> 开发中的战斗测试工具，部分规则与职业能力仍在接入；具体支持范围以项目文档为准。
